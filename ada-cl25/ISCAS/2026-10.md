### 其他交付物

- **后端可靠性与异步执行**：提供显式数据库升级和旧数据导入方式；Redis 支持短期空值缓存、重建锁、随机过期时间及回源限制，精确案例 ID 查询可选 Bloom 过滤。任务与 Outbox 事件同事务保存，消息发布确认后由 Worker 领取执行，覆盖 Agent 调用、批准后的验证及记忆入库。测试覆盖重复提交、事务回滚、重复投递、断连、超时和旧审批拒绝；不将至少一次投递与幂等处理表述为任意模型或 SSH 操作的严格恰好一次执行。

- **向量检索与父子证据扩展**：接入 BGE-M3 Embedding 和 Qdrant，将 MySQL 原始案例通过异步索引任务转换为带来源、版本和内容摘要的子块。查询时由 Qdrant 召回相近子块，再回查 MySQL，按必要背景、任务阶段证据和必要相邻片段三层扩展，在预算内组织上下文。10 月 10 日验收时，18 条记忆、547 个向量块完成索引；禁止全案例和全块扫描后，16 次串行及小规模并发查询均通过，并核对重启后的数据保留。这证明检索链路可用，不等同于召回率或准确率提升。

- **多智能体算子开发与修复**：建立主 Agent、语义、实现、测试与审查四类角色，按需提取合同，先准备测试，再生成候选并独立审查；审批、文件写入和远端执行仍由程序控制。使用隔离角色会话和结构化输出，保留固定验收测试及限次修复。11 月 3 日补充验收中，新算子经真实模型生成、审批和 sg2044 执行后通过 8 个 shape/dtype 组合；后续对照中也记录了首份实现编译失败、自动创建修复子任务并重新通过测试的案例。

- **角色用量统计与降本优化**：按角色和修复链累计输入、输出、可观测缓存 token、耗时及失败调用，缺失用量标为未知。审查输入去掉重复候选源码，已有冻结合同不再重复提取；同一修复链在合同、测试、源码及配置等条件通过核对后复用准备结果，仍保留新实现的独立审查和真实验证。一次受控修复子任务配对中，调用数由 4 次降至 2 次，总 token 由 11,849 降至 6,559，减少 44.65%，两组均通过 8 个验收组合；统计不含父任务准备成本，不推广为整个产品的普遍节省比例。

- **可选并行调查与模型路由**：支持主 Agent 提出独立只读子任务，用户批准后在隔离会话中执行。11 月 3 日将并行审批接入多智能体工作流，验证批准后两个子会话实际执行、拒绝后不创建子会话且正常继续处理，写入和测试仍需独立审批。完成 Luna、Terra、Sol 三个网关模型的只读 MCP 样例及路由链路测试；因未证明轻量模型更快或实际收费更低，保留 Sol 默认，轻量模型仅作为显式可选方案，不宣称路由已经实现稳定降本。

- **账号隔离与工作台体验**：加入注册登录、Argon2id 密码哈希、HttpOnly Cookie、CSRF 和登录限流，按登录身份隔离会话、任务、审批、文件及工作区。通过真实浏览器验证双账号隔离、跨账号 ID 访问拒绝、退出后 Cookie 失效、跨标签页切换和迟到响应丢弃。保留深色工作台及审批交互；11 月 4 日补充源码、测试、补丁、回执和日志的可点击只读预览，并限制跨账号路径、路径穿越及不安全文件访问。

- **测试规范与交付留证**：统一使用 Vitest 作为自动化测试入口，既有 Python 回归通过桥接保留，新断言使用 Vitest；插件拆分 PR 的 pre-commit 和 Vitest CI 已通过。补充临时 MySQL、Redis、RabbitMQ、Qdrant 集成检查、干净环境安装及打包验证；保留真实实验的模型输入输出、补丁、测试命令、日志、回执和用量，区分本地测试、真实模型调用与远端数值验证，不将嵌套测试计数重复累加。
