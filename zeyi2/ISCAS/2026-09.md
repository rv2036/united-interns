### 本月工作总结

本月主要在 LLVM 上游围绕 clang-tidy 和 RISC-V 展开工作，共计 30 个 PR 在九月合入；另有 5 个九月提交的 PR 仍在 review 中。此外，向 riscv-opcodes 提交并合入 1 个 PR，向 XUANTIE-RV thead-extension-spec 提交 1 个 PR（仍在 review 中），并向 openhwfoundation/cv32e40p 报告 1 个 Issue。

- clang-tidy：完成 readability 模块检查器文档从 reST 到 Markdown 的 rename/rewrite（共 5 组，其中 [5/5] 仍在 review）；修复 `bugprone-macro-parentheses` 对别名名的误报、`sizeof...` 表达式中参数包的重命名问题，以及 `function-cognitive-complexity`、`convert-member-functions-to-static`、`bugprone-misplaced-pointer-arithmetic-in-alloc` 的崩溃；优化 `misc-static-initialization-cycle` 的性能；修复 clang-tidy 作为 Clang frontend plugin 加载失败的问题（review 中）。
- RISC-V：新增 FCVT.H.Q/FCVT.Q.H 的 MC 支持；合入 Smidctrl/Ssidctrl/Smnip/Ssnip 实验扩展；完善 SiFive CLIC preemptible handler 支持，禁用相关 shrink wrapping 并支持 frame pointer；修复多组厂商扩展的 MC/反汇编问题，包括 HINVAL 依赖 H 扩展、Zvabd 依赖 Zve32x、XCVsimd 立即数范围、`cv.insert` 组合立即数校验、XTHeadMemIdx load-update、`qc.inw` 目标寄存器、XAndesVSIntH 依赖 Zve32f 等；推进 Zibi 升级到 0.7 版本（review 中）。
