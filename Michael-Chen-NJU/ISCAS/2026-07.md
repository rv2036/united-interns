### 本月工作总结

本月继续在 LLVM 上游社区推进 RISC-V P-extension 支持和中端/后端优化修复，共合入 4 个 PR，另有 2 个 PR 仍在 review 中。RISC-V 方向主要补齐 `riscv_packed_simd.h` 中 packed widening/narrowing convert 以及 packed pair byte 相关 intrinsics，并复用通用 IR、shuffle lowering 和已有后端选择逻辑，尽量避免为 header API 引入额外的 target-specific builtin 路径。优化与正确性方向主要围绕 ScalarEvolution 缓存失效问题展开，修复 full unroll 后 stale SCEV 信息可能导致后续 IndVars 错误折叠可达出口的问题，并继续把同类思路扩展到 LoopFlatten；此外还提交了 SelectionDAG 中带 add offset 的 shifted range check 改进。

### 本月提交的 PR

- [[LoopFlatten] Invalidate SCEV after flattening loops](https://github.com/llvm/llvm-project/pull/212744) - 在 loop flattening 成功后失效 ScalarEvolution 相关缓存，避免后续 loop pass 使用 stale SCEV 信息（+48/-2）
- [[SelectionDAG] Improve shifted range checks with add offsets](https://github.com/llvm/llvm-project/pull/207955) - 改进 SelectionDAG 对带加法偏移的 shifted range check 的识别与优化，覆盖 X86/SelectionDAG 场景（+213/-7）

### 本月合并的 PR

- [[Clang][RISCV][P-ext] Support packed widening convert intrinsics](https://github.com/llvm/llvm-project/pull/208394) - 为 RISC-V P-extension 补充 packed widening convert intrinsics，低半部分使用 `__builtin_convertvector`，高半部分使用通用 shuffle 生成正确代码（+387/-2）
- [[LoopUnroll] Invalidate SCEV after full unrolling](https://github.com/llvm/llvm-project/pull/208874) - 在 full unroll 后失效 ScalarEvolution loop/disposition cache，修复 stale exit count 信息导致后续 IndVars 误优化的问题（+59/-0）
- [[RISCV] Add packed narrowing convert intrinsics](https://github.com/llvm/llvm-project/pull/210389) - 为 `pncvt`/`pncvth` 添加 packed narrowing convert header API，并通过通用 IR 复用 RV32/RV64 现有 lowering 与 TableGen alias（+250/-0）
- [[Clang][RISCV] Add packed pair byte intrinsics](https://github.com/llvm/llvm-project/pull/212589) - 为 P-extension packed pair byte 形式补充 intrinsics，扩展 packed pair shuffle lowering 以识别 mixed even/odd 形式并选择 `ppaireo`/`ppairoe`（+898/-17）
