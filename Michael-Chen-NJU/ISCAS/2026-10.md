### 本月工作总结

本月继续在 LLVM 上游社区围绕 RISC-V P-extension intrinsics、MLIR 优化及 CodeGen 正确性开展工作，共新提交 7 个 PR，其中 6 个已合入；加上前期提交、本月合入的 MLIR 无符号模数修复，本月共合入 7 个 PR。RISC-V 方向补充 Q-format widening accumulate、narrowing shift、narrowing clip 和 byte horizontal multiply-accumulate 支持；MLIR 方向修复无符号模数处理、常量 affine.min 操作数的循环特化及循环范围折叠的重访问题，并提交 PHI elimination 中调试指令影响活跃区间裁剪的问题修复。

### 本月提交的PR

- [[CodeGen] Ignore debug uses when trimming PHI source live intervals](https://github.com/llvm/llvm-project/pull/236614) - 查找 PHI 源寄存器的最后一次读取时跳过调试指令，避免 EH successor 场景下将 `DBG_VALUE` 误作 kill instruction 并传入 `getInstructionIndex`；补充单个及相邻 `DBG_VALUE` 的 MIR 回归测试，覆盖两种 pass manager。

### 本月合并的PR

- [[mlir][arith] Handle unsigned moduli in int-range optimizations](https://github.com/llvm/llvm-project/pull/224933) - 修复 `DeleteTrivialRem` 将常量模数按有符号值读取的问题，保留 `APInt` 位模式并按余数操作的有/无符号语义处理，使 `remui` 能够正确处理最高位为 1 的无符号模数。
- [[Clang][RISCV][P-ext] Add packed Q-format widening accumulate intrinsics](https://github.com/llvm/llvm-project/pull/228009) - 补充 `__riscv_pmqwacc_i32x2` 和 `__riscv_pmqrwacc_i32x2`；RV32 选择直接指令，RV64 按规范展开为 `zip16p` 与 packed Q-format accumulate 的组合序列。
- [[Clang][RISCV] Add packed narrowing shift intrinsics](https://github.com/llvm/llvm-project/pull/228726) - 补充 packed narrowing shift intrinsics，覆盖逻辑右移、算术右移及带舍入的算术右移形式。
- [[mlir][scf] Specialize loops with constant affine.min operands](https://github.com/llvm/llvm-project/pull/228909) - 在循环特化前规范化 affine map 及操作数，识别通过 map operands 传入的常量，修复只检查 map results 导致遗漏循环特化机会的问题。
- [[Clang][RISCV] Add packed narrowing clip intrinsics](https://github.com/llvm/llvm-project/pull/231398) - 补充 packed narrowing clip intrinsics，覆盖有符号与无符号结果，以及带舍入和不带舍入的形式。
- [[Clang][RISCV] Add packed byte horizontal multiply-accumulate intrinsics](https://github.com/llvm/llvm-project/pull/234484) - 补充 `__riscv_pm4adda_i8x8`、`__riscv_pm4addau_u8x8` 和 `__riscv_pm4addasu_i8x8`，复用 packed dot-product intrinsics 与通用 vector addition；RV64 选择一条 byte multiply-accumulate 指令，RV32 按两个 word 分别选择指令。
- [[mlir][scf] Revisit affected loops during range folding](https://github.com/llvm/llvm-project/pull/230961) - 将循环范围折叠改为 `OpRewritePattern<scf::ForOp>`，通过 `applyPatternsGreedily` 重访受影响的循环，使外层循环折叠后新暴露的内层循环优化机会能够在一次 pass 调用内得到处理。
