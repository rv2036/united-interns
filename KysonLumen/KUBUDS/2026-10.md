#### 一、thrift: 修复 CVE-2026-94639（Java SASL nonblocking server）

- 回移上游 `299a678f`、`175e803d`、`32530798` 三个提交到 0.14.1 分支，修复 SASL 网络线程在连接级异常或内存分配失败时被终止、而服务端仍继续接受连接的问题。
- 处理与 master 的冲突：CVE-2026-94639 补丁调整为 `Patch5`，保留已合入的 CVE-2026-96292 `Patch4`，Release 提升至 `0.14.1-4`，changelog 保留两条记录。
- 回归测试适配 0.14.1 的源码布局与 JUnit 4 接口，改为自包含 SASL fixture，规避需要代码生成的 `TestTSaslTransports` 依赖。
- 验证：完整 Java 库在源码包与 spec 中 Maven sources 两条路径均编译通过，19 项 SASL 测试全部通过；对未打补丁的 Maven Central libthrift 0.14.1 运行 11 项定向测试有 6 项失败，打补丁后全部通过（Zulu OpenJDK 8u504 / JUnit 4.12）。

#### 二、openEuler kernel (OLK-6.6): 修复 CVE-2026-98265

- 回移上游 `76a986c9`，修复 USB 音频隐式反馈源上报包数量超出数据 URB 描述项容量导致的越界写入：记录实际分配容量，并限制采纳的包数量与包长度复制次数，分配前统一计入 Format Type II delimiter。
- 适配 OLK-6.6 的 `for` 循环实现，使用限制后的 `ctx->packets` 作为循环上界。
- 验证：`git diff --check`、补丁正反向应用检查通过；`checkpatch --strict` 为 0 errors / 0 warnings / 0 checks；x86_64 下 `make -j2 sound/usb/` 通过（Ubuntu 26.04 WSL2 / GCC 15.2.0）。
- 说明：完整内核构建、模块装载、KASAN 与真实 USB 音频设备回归尚未执行，PR 中已标注，仅覆盖 OLK-6.6 分支。
